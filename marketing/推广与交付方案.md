# 小额销售实验：下载工作台

## 商业判断

下载进度本身替代品很多，单靠“AI 下载插件”很难形成持续付费。更值得尝试的受众是 Windows 新手：手里有一组文件直链，想一次下载、分类并知道哪些失败。

本轮已按这一判断实现：独立运行、中文流程、批量去重分类、真实演示、CSV 回执和隐私分享图。独立运行扩大受众；演示降低理解成本；回执减少查找失败文件的时间。是否有人付费仍需要实际销售验证。

## 产品与价格实验

| --- | --- | --- |
| 社区版 | MIT 源码、GitHub 公开发行包 | 免费 |

| 可选安装协助 | 约定的一台 Windows 电脑启动与一次功能演示 | 另加 29.9 元假设 |

以上不是已上线套餐或成交数据。不要承诺永久人工支持、无限设备、绕过登录、任意网页解析或网速翻倍。协助排期、工时和退款条件必须在成交前确定；当前未连接支付或店铺。

低价不是核心壁垒。把常见问题写清楚，让多数人能自助成功，比不断加功能更能保住小额收入。源码公开应在商品描述中直接告知。

## 抖音演示脚本（约 35 秒，草稿）

1. 0～5 秒：录制工作台空状态。“有一串文件链接，想知道哪些下完、哪些没成功？”
2. 5～12 秒：点击“运行本机演示”。画面保留“本机演示”标记。“这三个示例由本机生成，我用它演示流程。”
3. 12～22 秒：拍摄真实进度和分类目录。“批量排队，最多四个同时下载，同名文件会保留。”
4. 22～30 秒：生成分享图，展示真实完成数量。“回执可以导出，分享图默认隐藏文件名、链接和路径。”
5. 30～35 秒：“源码和公开发行包免费。需要整理好的上手资料和安装协助，可以看交付说明。”

先完整跑通再录制；允许剪去等待时间，但注明加速/剪辑，不能伪造速度。只展示演示目录，隐藏浏览器中的访问凭据与个人文件。

## 小红书六页图文（草稿）

1. 标题：一堆文件链接，怎么知道哪些真的下载完？
2. 输入：每行一个文件直链；附“仅直链，不解析网盘分享页”。
3. 过程：四个并发，其余排队；展示真实下载中的截图。
4. 结果：分类文件夹与完成、失败、跳过的不同含义。
5. 回执：展示本机演示海报，保留演示文字与真实数量。
6. 获取：明确源码和发行包免费；付费部分为整理交付与约定协助，附适用 Windows 和使用限制。

不编造客户反馈、销量和倒计时。平台当前的软件商品类目、经营资质及外链规则尚未确认，发布销售内容或上架前需在实际卖家后台确认；本文不意味着已获平台准入。

## 先做一个小实验

连续发布三条不同使用场景的真实演示，使用平台后台人工记录：曝光、收藏、有效咨询、下载后首次成功、实际购买、退款、每单协助分钟数。没有真实用户时全部留空。

优先看“能否自己成功一次”与“为什么咨询却不购买”。少量订单只能说明有人愿意尝试，不能推出稳定收入。若协助时间吞掉收益，先改指南和产品错误提示，再考虑继续卖。
