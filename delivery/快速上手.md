# 下载工作台 · 快速上手

## Windows 独立版

1. 把交付压缩包解压到 E 盘任意文件夹。
2. 双击 `DownloadWorkbench-0.3.0.exe`。程序会打开默认浏览器，本机后台负责下载；无需安装 Python 或 Codex。
3. 第一次先点击“运行本机演示”。这会在保存目录下创建一个独立的演示文件夹，下载三个自生成文件。
4. 使用自己的链接时，每行粘贴一个 HTTP/HTTPS 文件直链，最多 50 个，填写绝对保存路径后点击“开始批量下载”。
5. 完成后可以打开文件夹、导出 CSV，或生成隐藏文件名、网址、路径的分享图。演示分享图始终标注演示。
6. 结束时点击右上角“退出服务”。仅关闭浏览器标签页不会停止后台程序。

请只运行自己信任来源的程序。本版没有购买商业代码签名证书，Windows 可能显示发布者未知；如果不信任，先查看公开源码或使用源码版。不要关闭系统防护。

## 源码版与 Codex 版

源码免费公开，采用 MIT。源码版需要 Python 3.10+：

```powershell
python plugins/download-progress/scripts/workbench.py
```

Codex 插件安装方法见仓库 README。安装后新开一个对话，输入：

> 打开下载工作台，默认保存到 E:\下载\我的资料。

## 常见情况

| 情况 | 处理 |
| --- | --- |
| 网盘分享链接、视频网页下载失败 | 换成有访问权限的文件直链；本工具不解析分享页面，不登录账号 |
| 同名文件被跳过 | 原文件保留；跳过不代表原内容已校验。换一个目标目录下载 |
| 取消后仍短暂显示下载中 | 取消需要等待网络读取返回，单次等待最长约 30 秒 |
| 断网或退出后想恢复 | 重新提交相同链接到相同目录；有强 ETag 且服务器支持有效范围响应时才续传，否则安全重下 |
| 不显示百分比 | 服务器没有提供总大小，仍显示已下载字节与速度 |
| 重启后清单不见了 | 历史只保留在本次服务会话；下载好的文件和部分文件仍在磁盘 |
| 双击后浏览器没有自动打开 | 使用源码版查看报错；或通过命令行参数 `--info-file E:\下载\startup.json` 取得仅本机使用的打开地址 |

CSV 带文件名，请检查后分享。打开地址包含本机访问凭据，不要截图或转发。分享海报只反映该批次结果，不保证下载内容正确、合法或发布者身份可信。

## 交付与协助的边界

公开源码和公开发行包均可免费获取。若收取交付费，价值是整理好的上手资料、模板及约定范围内的协助；不是购买独占源码或特殊下载权限。
可选安装协助的设备数量、时间、系统要求和退款处理，应在购买前由卖家明确。当前项目没有支付系统，也未开通平台店铺。
